# iWillTravel Cinematic Asset Slots

Drop your generated video clips and 3D renders into these directories:

## Video Slots (`public/assets/videos/`)
- `kyoto-drone.mp4`: Drone sweep over Kyoto temples / bamboo grove at golden hour.
- `tokyo-neon.mp4`: POV bullet-train or high-speed rainy neon metropolitan drive through Shinjuku.
- `alps-flyover.mp4`: Alpine flyover across Swiss peaks / Glacier Express.

*Recommended Video Specs:*
- Codec: H.264 / MP4 (or WebM)
- Resolution: 1080p or 4K (optimized under 15MB for fast streaming)
- Audio: Muted or ambient soundscape (HTML5 `autoPlay loop muted playsInline` supported)

## 3D / Octane Render Slots (`public/assets/renders/`)
- `passport-terminal.png`: Futuristic glass passport terminal floating above topographic sand-dune.
- `boutique-stay-depth.png`: Octane-style architecture render of modern Japanese ryokan.
- `constellation-hero.png`: High-res static fallback render of the agent constellation globe.
